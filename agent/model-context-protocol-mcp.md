# Model Context Protocol (MCP)

## 背景與目的

隨著大型語言模型（LLM）在各個領域的廣泛應用，單靠模型內部的知識及推理能力已難以滿足愈發複雜的應用需求。儘管 LLM Agent 能夠模擬人類思考並進行對話，其運作本質上僅限於處理文字資訊，並未能夠直接連接外部資源，如數據庫、檔案系統和第三方 API。

為了解決這一限制，Anthropic 等公司提出了模型上下文協議（[Model Context Protocol, MCP](https://modelcontextprotocol.io/introduction)）。其目的是讓 LLM Agent 能夠：

* 以標準化的方式連接外部數據和工具。
* 運用模組化設計來擴展其功能與應用範圍。
* 透過 MCP，LLM Agent 的能力將能進一步增強，滿足更複雜的需求和挑戰。

## MCP 的定義與主要功能

**MCP 是什麼？**

MCP 是一套開放標準協議，主要目的在於規範 AI 應用與外部資源（如工具、數據、提示模板等）之間的通信。簡單來說，它就像是 AI 系統與各種外部服務之間的「USB-C 接口」，讓不同的工具和數據來源能夠輕鬆接入 LLM Agent 的運作流程。

**主要功能包括：**

* **工具（Tools）：** 透過 MCP，外部工具（例如計算器、搜尋引擎、資料庫查詢工具等）可以以統一介面供 Agent 呼叫，實現自動化操作與即時回饋。
* **資源（Resources）：** 提供數據或內容，作為 Agent 在回答問題或執行任務時的上下文信息。
* **提示與取樣（Prompts & Sampling）：** 定義可重複使用的提示模板，或讓 Agent 透過取樣功能獲取額外的語言模型回應。
* **根（Roots）：** 定義數據及資源的邊界，協助 Agent 有效管理並定位所需上下文。

## MCP 的架構

MCP 採用**客戶端–伺服器架構**，其核心組件包括：

* **MCP 主機／客戶端（Host/Client）：**\
  這部分通常為 LLM Agent 本身（例如 Claude Desktop、IDE 插件等），負責發起與外部資源的連線請求。
* **MCP 伺服器（Server）：**\
  輕量化的伺服器程式負責連接特定的外部數據源或工具（如文件系統、資料庫、第三方 API 等），並將其功能以標準化介面提供給 Agent。
* **通訊協議層：**\
  MCP 通常基於 JSON-RPC 或 gRPC 等標準通信協議，確保主機與伺服器間的消息傳遞既安全又高效。

這樣的架構不僅提升了系統整合的靈活性，也大大降低了開發者為每個工具單獨實現連接器的成本

## MCP 在 LLM Agent 中的應用

利用 MCP 協議，LLM Agent 可以獲得以下能力：

* **擴展上下文信息：**\
  Agent 不再僅限於內部訓練數據，而是能夠透過 MCP 連接到實時數據源，如最新新聞、資料庫記錄、文件內容等，從而生成更具時效性和針對性的回答。
* **動態工具調用：**\
  當面臨需要執行特定操作（如計算、查詢、文件操作等）時，Agent 可根據任務需求自動選擇並調用對應的 MCP 工具，完成如同小秘書般的動作。
* **跨平台整合：**\
  由於 MCP 採用開放標準，無論 Agent 使用哪家公司的 LLM 或運行於何種平台，只要實現了 MCP 接口，均能輕鬆整合各種外部服務，形成互聯互通的生態系統

## MCP 的優勢

* **統一性與標準化：**\
  MCP 透過標準化的介面，一次開發即可對接多種外部資源，避免針對每個工具單獨開發連接器的繁瑣流程，進而大幅降低開發與維護成本。
* **安全性：**\
  協議內建權限控制與安全機制，可限制 Agent 僅取得必要數據，避免敏感信息不當洩露。
* **擴展性：**\
  MCP 支援模組化設計與插件擴展，開發者能根據具體應用需求輕鬆添加新的 MCP 伺服器，滿足多元化的業務場景。
* **跨平台互操作：**\
  因為 MCP 是一套開放標準，不受限於特定平台或廠商，使得不同 LLM Agent 之間能共享同一套接口與工具，促進生態系統發展。

## 實際案例與未來展望

**案例應用：**

目前已有許多企業和開發者利用 MCP 實現了包括文件管理、數據查詢、自動化任務等多種應用。例如，在金融領域中，Agent 可根據即時匯率資訊透過 MCP 工具快速完成換匯決策；在企業內部，Agent 能夠整合多個資料庫，進行跨系統數據檢索與任務協同。

**未來展望：**

隨著 AI 應用日益普及，MCP 將可能成為連接各類外部數據資源的標準橋梁。隨著生態系統的日益成熟，預期將有更多基於 MCP 的工具與服務湧現，進一步豐富 LLM Agent 的應用場景，並為企業提供更高效、更智能的解決方案。
